# Inbox Management Playbook

**Fictional portfolio practice sample.** This is a demonstration workflow for an invented consultant. The messages, people, dates, and scenarios below are fictional; this is not client work or a claim of measured results.

## Purpose

Make it easy to see what needs a reply, what is waiting on someone else, and what belongs on the calendar. Adapt the timing and permissions with the account owner before using this workflow.

## Label map

| Label | Apply when | Next step |
| --- | --- | --- |
| 01 / Action today | An agreed deadline is today or a time-sensitive decision is needed | Flag for the owner; draft an answer within the agreed scope |
| 02 / Reply this week | A response is needed but there is no immediate deadline | Add to the next reply block |
| 03 / Waiting | A reply or document is needed from another person | Record who owes what and the follow-up date |
| 04 / Calendar | A meeting request or schedule change is involved | Check availability, time zone, and meeting purpose |
| 05 / Reference | A useful message needs no action | Archive with the reference label |
| 06 / Newsletters | A subscription or nonessential update arrives | Review in a separate reading block |

## Triage rules

1. Read for the requested action and any explicit deadline before deciding priority.
2. Keep a message in one action state. Add a topic label only if it helps retrieval.
3. For a reply within the assistant's authority, draft or send according to the owner's agreed policy. Escalate decisions outside that policy.
4. For a calendar request, confirm the time zone, duration, participants, and meeting goal. A suggested time is not a confirmed booking.
5. For a waiting item, record the next review date before archiving the thread.
6. Review suggested filters before enabling them. Avoid automatically archiving unfamiliar senders or messages containing deadlines.

## Daily review: two short blocks

**Morning**

- Check time-sensitive threads and calendar changes.
- Sort new messages using the label map.
- Draft responses that fall within the agreed scope.
- Send the owner a compact summary: decision needed, context, deadline, and suggested next action.

**End of day**

- Review today's waiting items.
- Confirm every open action has an owner and next review date.
- Check tomorrow's meetings for missing links, agendas, or documents.
- Archive completed threads.

## Weekly cleanup

- Review stale waiting items and decide whether to follow up, close, or escalate.
- Check labels for duplicates and misfiled conversations.
- Review newsletters and request approval before unsubscribing on the owner's behalf.
- Adjust any filter that hides important messages.
